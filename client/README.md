## โครงสร้างทางเทคนิคของระบบ (Technical Overview)

### 1.ไฟล์ในโปรเจกต์ (File Structure)
* `server.js` — Express Backend Server สำหรับให้บริการ REST API, Caching และ Geocoding Lookup
* `src/App.jsx` — Main Application Component จัดการสถานะหลัก (State Management), Dynamic Theme Switcher และ UI Feedback
* `src/App.css` / `src/index.css` — สไตล์ชีตและการกำหนด Animation สภาพอากาศ (Sunlight, Rainfall, Cloud Drift)
* `src/components/` — ที่เก็บ UI Components ย่อยทั้งหมดของระบบ

### 2.คอมโพเนนต์ (Components)
* `ProvinceSelector` — ส่วนค้นหาและเลือกจังหวัด พร้อมระบบ Auto-complete
* `HomeTravelSuggestions` — ส่วนแนะนำสถานที่ท่องเที่ยวหน้าแรกก่อนเลือกจังหวัด (New Feature)
* `WeatherCard` — การ์ดแสดงผลอุณหภูมิ สภาพอากาศปัจจุบัน และความชื้น
* `RainCard` — การ์ดพาดหัวแจ้งเตือนคาดการณ์ฝนที่จะตกในระยะสั้น
* `AdviceCard` — การ์ดคำแนะนำการเตรียมตัว (เช่น พกร่ม, ทาครีมกันแดด, พกน้ำดื่ม)
* `ForecastCard` — รายงานสภาพอากาศและอุณหภูมิสูงสุด-ต่ำสุดล่วงหน้า
* `TourismRecommendation` — ส่วนแนะนำสถานที่ท่องเที่ยวเฉพาะจังหวัดพร้อมสภาพอากาศของสถานที่นั้นๆ (New Feature )

### 3.เส้นทาง API (Backend Routes)
* `GET /provinces` — ส่งคืนรายชื่อจังหวัดทั้งหมดในประเทศไทยที่เรียงลำดับอักขระแล้ว
* `GET /weather?province={name}` — ดึงข้อมูลสภาพอากาศ คาดการณ์ฝน และคำแนะนำประจำจังหวัด
* `GET /destination-weather?destination={place}&province={name}` — ดึงพิกัดและสภาพอากาศเฉพาะของสถานที่ท่องเที่ยวนั้นๆ

### 4.โครงสร้างข้อมูลและอัลกอริทึม (DSA Breakdown)
* **Selection Sort Algorithm:** ใช้จัดเรียงรายชื่อ 77 จังหวัดตามอักขรานุกรมภาษาไทยแบบ Custom ในเซิร์ฟเวอร์
```javascript
function selectionSort(items) {
  const sorted = [...items];
  for (let i = 0; i < sorted.length - 1; i += 1) {
    let minIndex = i;
    for (let j = i + 1; j < sorted.length; j += 1) {
      if (sorted[j].localeCompare(sorted[minIndex], 'th') < 0) minIndex = j;
    }
    [sorted[i], sorted[minIndex]] = [sorted[minIndex], sorted[i]];
  }
  return sorted;
}
